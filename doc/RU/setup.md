## Первая установка.
Вы можете **найти** информацию о первой установке в файле `README.md`. 

## Все конфигурационные параметры.

- `whitelist.json`
Файл находится по пути: ваша_папка/whitelist.json (корневая папка CnUlP.)

**Шаблон**

```json
{
    "friends": [
        {
            "ip": "192.168.100.2",
            "uuid": "4a727ed3-b5c3-4973-a422-c5e62b728c4c",
            "name": "teto pear =d"
        }
    ]
}

```
Параметр: "ip": локальный IP вашего пира (человека, который хочет к вам подключится.).

Параметр: "uuid": ваш UUID из файла my_personality.json.

Параметр: "name": ваше имя.

- `sites.json`
Файл находится по пути: ваша_папка/sites.json (корневая папка CnUlP)

**Шаблон**

```json
{
    "sites": [
        {
            "site": "10.0.0.5",
            "name": "RULE 34 OFFICIAL SITE",
            "owner_uuid": "cc4c4a62-fedd-42b9-971d-d73c3ac6eafe"
        }
    ]
}

```
Параметр: "site": IP сайта.

Параметр: "name": Имя сайта.

Параметр: "owner_uuid": Кто владеет сайтом? (в формате UUID, из файла my_personality.json.)

- `my_personality.json`
Файл находится по пути: ваша_папка/my_personality.json (корневая папка CnUlP)

**Шаблон**

```json
{
    "my_uuid": "42c56892-0ba7-47fe-8881-27a83e1cce72",
    "virtual_ip": "10.0.0.1/24"
}

```

Параметр: "my_uuid": НЕ ИЗМЕНЯЙТЕ этот параметр. Он был генерирован автоматически после первого старта/или если вы удалили файл: "my_personality.json".

Параметр: "virtual_ip": Ваш IP в системе CnUlP.
